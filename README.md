# Skin Cancer Detection using Random Forest

A machine learning web application for classifying skin lesion images using the **Random Forest** algorithm. The application is built with **Python** and **Streamlit**, and uses **Grad-CAM** to provide visual explanations that highlight important regions of the input image.

## Features
- Upload skin lesion images
- Skin image validation
- Random Forest-based prediction
- Grad-CAM visualization for model interpretability
- Simple and user-friendly Streamlit interface

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- OpenCV
- Grad-CAM
- NumPy
- Pandas
